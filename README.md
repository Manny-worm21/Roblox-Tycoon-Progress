I decided to play around with making Roblox games. The only way to make Roblox games is using Roblox Studio and Roblox uses the Lua language to program the games. 

I does seem complicated at first, but it can be understandable after watching a few tutorials. It does seem interesting to do and I could see myself passionately making more games later on down the road. Though it does have a tough debugging process with how different objects interact with one another.

Currently, it is a tycoon about fish. Where you start of a small fish factory and over time grow into a massive fish business. I haven't added the part of the increased fish business, but will be added once I get through some other plans I want to add first. 

I am just adding decorations in certain areas of the game and balancing the economy to make a little hard to earn money.
